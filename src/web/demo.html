Pulseboard — talk to Pulse 📈

Pulse is a production-style AI sales agent: it qualifies leads, answers pricing from live business data, shares customer results, and books discovery calls. This page and the agent API are served by one Cloudflare Worker.

Try the full sales flow 👇 1. Ask about pricing  2. Ask for proof  3. Book a call — then ask "what did I book?" in a later message.
Reload the page: the same conversation id () resumes with full history. That is durable execution.
Built with Flue: agent Sales + tools get_pricing, get_case_studies, book_meeting (durable state). API: POST /agents/sales/:id per message, GET /agents/sales/:id for history.
